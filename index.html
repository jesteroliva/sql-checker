Welcome to SQL Query Excel Tool

This tool allows you to load Excel files (XLSX) and CSV files into an in-memory SQL database and query them using standard SQL commands. Key features include:

  • Load multiple Excel/CSV files into SQL tables
  • Run SQL queries across all loaded data
  • Export results to CSV or Excel format
  • Save query results as new tables
  • Join data across multiple sheets or files

All processing happens in your browser - no data is sent to any server.
