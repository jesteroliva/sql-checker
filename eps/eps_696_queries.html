EPS 696 - SQL Queries

Step by Step SQL Query

Step 1: Basic SELECT Query

This step demonstrates how to select all columns from a table.

SELECT * FROM students;

This query will return all records from the 'students' table, displaying all columns.

Step 2: Filtering with WHERE Clause

This step shows how to filter results based on specific conditions.

SELECT first_name, last_name, gpa
FROM students
WHERE gpa > 3.5;

This query returns only the first name, last name, and GPA of students who have a GPA greater than 3.5.

Step 3: Joining Tables

This step demonstrates how to join data from multiple tables.

SELECT students.first_name, students.last_name, courses.course_name
FROM students
JOIN enrollments ON students.student_id = enrollments.student_id
JOIN courses ON enrollments.course_id = courses.course_id
ORDER BY students.last_name ASC;

This query joins the students, enrollments, and courses tables to display which students are enrolled in which courses, sorted alphabetically by last name.

Step 4: Aggregation Functions

This step shows how to use aggregation functions like COUNT, AVG, and GROUP BY.

SELECT department, COUNT(*) as num_students, AVG(gpa) as avg_gpa
FROM students
GROUP BY department
HAVING COUNT(*) > 5
ORDER BY avg_gpa DESC;

This query counts the number of students in each department and calculates their average GPA, showing only departments with more than 5 students, sorted by the highest average GPA.

Step 5: Subqueries

This step demonstrates how to use subqueries for more complex data retrieval.

SELECT first_name, last_name, gpa
FROM students
WHERE gpa > (SELECT AVG(gpa) FROM students)
ORDER BY gpa DESC;

This query finds students whose GPA is higher than the average GPA of all students, sorted by GPA in descending order.
